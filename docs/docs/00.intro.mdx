# Introducción a ULYTICS

Bienvenido a la documentación técnica de **ULYTICS**, la plataforma oficial de reportería de indicadores de **Progresión Académica y Curricular**.

## ¿Qué es ULYTICS?
ULYTICS es una plataforma web desarrollada para generar, centralizar y visualizar reporterías de indicadores académicos. Su objetivo principal es facilitar a las autoridades institucionales, decanos y directores de carrera el seguimiento de las cohortes a través del tiempo, permitiendo una toma de decisiones basada en evidencia. 

El sistema consolida información institucional para reducir la complejidad de analizar reportes extensos o dispersos, apoyando directamente al Sistema de Aseguramiento Interno de la Calidad y los procesos de autoevaluación.

## Objetivos del Proyecto
* **Centralizar la visualización** de indicadores académicos y curriculares relevantes.
* **Analizar la evolución de las cohortes** mediante gráficos, tablas y filtros interactivos.
* **Identificar tendencias y rezagos curriculares**, así como asignaturas con comportamientos críticos.
* **Proporcionar información útil** para la autoevaluación, aseguramiento de la calidad y la toma de decisiones directivas.

## Perfiles de Usuario
El acceso a la información en ULYTICS se restringe dinámicamente según el rol y el ámbito académico del usuario:
* **Autoridad Central:** Acceso transversal a nivel institucional (Sede, Campus, Facultad o Carrera) para analizar el estado general de la Universidad.
* **Decano:** Visualiza únicamente la información agregada y específica de las carreras que componen su Facultad.
* **Director de Carrera:** Acceso restringido exclusivamente a las cohortes e indicadores de su respectiva carrera.
* **Administrador:** Encargado de la configuración de parámetros, gestión de accesos, carga y validación de datos académicos.

## Stack Tecnológico Principal
Nuestra arquitectura está diseñada para ser escalable, utilizando tecnologías modernas de la industria:

* **Frontend:** React + Tailwind CSS (con componentes de shadcn/ui y gráficos interactivos mediante Recharts).
* **Backend:** Node.js + Express para una API RESTful eficiente.
* **Persistencia de Datos:** Base de Datos relacional en PostgreSQL, utilizando Sequelize como ORM.
